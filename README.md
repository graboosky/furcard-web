# PetID — Web

An ID card for your pet — a profile with its photo, species, breed, age and food, a
vaccination calendar that reminds you when the next shot is due, seasonal reminders such as
tick season, and its vet's details.

This is PetID's public site: the privacy policy and support pages the App Store and Google
Play link to, served by GitHub Pages at <https://graboosky.github.io/petid-web/>. It is part
of the PetID container — start at `../CLAUDE.md`; this repository's own conventions are in
`CLAUDE.md`.
