# Furcard — Web

An ID card for your pet — a profile with its photo, species, breed, age and food, a
vaccination calendar that reminds you when the next shot is due, seasonal reminders such as
tick season, and its vet's details.

This is Furcard's public site: the privacy policy and support pages the App Store and Google
Play link to, served by GitHub Pages at <https://graboosky.github.io/furcard-web/>. It is part
of a private container (working name PetID) — there, start at `../CLAUDE.md`; this repository's
own conventions are in `CLAUDE.md`.
